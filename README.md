# CodeAlpha Task 3 - Automation Script

This Python script automatically moves all `.jpg` files from one folder to another.
It uses the `os` and `shutil` modules for file handling.

## How to Run
1. Place `.jpg` files in the source folder.
2. Run the script using:
   python automation.py
3. The files will be moved to the destination folder.

## Technologies Used
- Python
- OS module
- Shutil module
